# Changelog

All notable changes to the WW1 & WW2 Agentic Trivia CLI are documented here.

---

## [v2.6] — 2026-03-17

### Answer Deduplication — Runtime & Offline

#### Changes
- **Runtime:** Added `seen_answers: set[str]` to `GameState` — the quiz engine now strictly tracks the normalized form of every answer shown in a session, preventing the same concept from appearing twice even when phrased differently (e.g. "General Patton" vs "George S. Patton").
- **Topic Fallback:** When a selected topic has insufficient questions, the game now falls back to the full bank while still enforcing both `seen_questions` and `seen_answers` globally.
- **VS Mode:** `draw_vs_questions()` now runs answer deduplication during the upfront question draw, so all players who share a seed get a semantically clean, non-repeating quiz.
- **`dedupe_bank.py` (new tool):** Offline developer utility to scan `questions.enc`, semantically verify duplicate answers using `gemini-2.5-flash`, and replace them one-for-one with fresh questions preserved to the same topic and difficulty.
- **`normalize_answer()`** exported from `database.py` for use by `dedupe_bank.py` and `main.py`.
- **Regression tests:** Two new tests in `adversary/test_regression.py` — `test_no_duplicate_answers_in_session` and `test_topic_fallback_respects_deduplication`.

## [v2.5] — 2026-03-16

### Game Modes, Multi-Bank Support & Paranoia Checker

#### Changes
- **Adaptive Mode:** Default mode. Difficulty scales up/down based on player performance. Seeds are hidden.
- **VS Mode:** Deterministic mode. Questions are drawn upfront based on a shared seed (`VS:XXXXXX@vN`), ensuring two players face the same set. Seed is prominently displayed for easy sharing.
- **Configurable quiz length:** Players choose how many questions at game start (default: 20).
- **Multi-bank support:** Custom banks can be created, stored in `banks/<name>.enc`, and tracked in `banks/index.json`. The official bank (`questions.enc`) is updated only via OTA.
- **Bank selection UI:** Settings → Manage Bank → Select Active Bank to swap between available banks.
- **`seed_bank.py`:** Custom bank generator with minimum 20 questions, model/topic selection, and graceful error handling (rate limit, invalid API key).
- **`adversary/paranoia_checker.py`:** Structural health-check script covering import sanity, DB integrity, seed roundtrip, VS determinism, history persistence, and bank index validity.
- **README updated** with Adaptive vs VS mode documentation and custom bank usage guide.

## [v2.4] — 2026-03-15

### OTA Updates, Bank Versioning & Simulation Agent

#### Changes
- **OTA update system:** On launch, `wwq.bat`/`wwq.sh` pull the latest `questions.enc` from GitHub. If the user has a custom bank active, the official bank is updated silently in the background without disrupting their session.
- **Bank version stamping:** `questions.enc` now includes a `bank_version` integer. Seeds embed the version (`VS:XXXXXX@v2`) so players can detect mismatches.
- **`adversary/simulate_games.py` (new):** Agent that simulates gameplay at configurable skill levels (`beginner`, `intermediate`, `expert`, `random`), generating realistic `question_history.json` data without manual play. Used for driving `refresh_db.py`.
- **`refresh_db.py`:** History-driven partial bank refresh — retires most-asked questions and replaces them via the Gemini API.
- **Settings: Bank Management menu** added to the in-game settings for switching and inspecting banks.

## [v2.3] — 2026-03-15

### Seed Condensation & Backward Compatibility

#### Changes
- Seeds condensed from long Base64 strings to short 6-char alphanumeric codes (`AAAAAA`).
- `generate_seed()` / `decode_seed()` updated with backward-compatible Base64 fallback for old seed formats.
- Topic suffix format: `XXXXXX:Topic` for custom topics.

---

## [v2.2] — 2026-03-15

### Question History & Weighted Sampling

#### Changes
- `question_history.json` persists ask counts, session history, and last-asked session per question.
- `get_question()` uses inverse-frequency weighting — over-used questions are much less likely to appear.
- Hard cooldown: questions asked in the last N sessions have zero weight.
- `WEIGHT_FLOOR` prevents any question from having zero weight permanently.
- Tests: `TestQuestionHistory` suite added.

---

## [v1.0] — 2026-03-15

### Initial Release

#### Features
- 2,046 encrypted WW1/WW2 trivia questions generated by Gemini 2.5 Flash.
- Fernet-encrypted `questions.enc` with static embedded decryption key.
- Multiple-choice 4-option format with difficulty 1–5.
- Rich CLI with colored output, score tracking, and end-game review matrix.
- Basic `seen_questions` deduplication within a single session.
- Settings menu: switch LLM provider (local_bank, Gemini, Ollama, OpenAI), topic, difficulty override, API key.
- `generate_db.py` + `encrypt_db.py` developer tools.
- `wwq.bat` / `wwq.sh` launchers with automatic venv provisioning.
